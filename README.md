# DonutPLUS

A Fabric mod that provides technical features and quality-of-life (QoL) improvements.

## Disclaimer

DonutPLUS was created to add features specifically needed for DonutSMP. If a feature is not currently included, do **not** download unofficial versions or addons from third-party websites, as they may contain malware or other security risks.

The official source for DonutPLUS is:
