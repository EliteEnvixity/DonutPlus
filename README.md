# DonutPLUS

A Fabric mod that provides technical features and quality-of-life (QoL) improvements designed specifically for DonutSMP

## Disclaimer

DonutPLUS was created to add features specifically needed for DonutSMP. If a feature is not currently included, please do **not** download unofficial versions, addons, or "fixes" from third-party websites, as they may contain malware, modified code, or other security risks.

The only official source for DonutPLUS is:

**GitHub:** https://github.com/EliteEnvixity/DonutPlus

Any downloads from other websites are not guaranteed to be safe or up to date.

## Installation

1. Install Fabric Loader.
2. Download the latest release from the official GitHub repository.
3. Place the `.jar` file in your Minecraft `mods` folder.
4. Launch Minecraft using the Fabric profile.

## Compatibility

- Requires Fabric Loader.
- Intended for use with DonutSMP.
- Compatibility with other mods may vary.
